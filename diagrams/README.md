# Diagrams

Every chart and diagram drawn as SVG in the handbook is exported here as a standalone, light-theme `.svg` file each time `_build/build.py` runs (file names: `<section>-<number>-<title>.svg`). Use them in slides, documents or portfolio pieces.

- Data in charts is **hypothetical or synthetic** unless the caption says otherwise.
- Wireframes are **illustrative**, not screenshots of real products.
- Canvas-style figures (SWOT, BMC, PESTLE, etc.) and comparison tables are HTML, not SVG, so they are not exported here — find them in the site or PDFs.
